# Matriz de Trazabilidad Filosófica — SOEC

> **Qué es.** Documento auxiliar (no forma parte de la Constitución). La Constitución es la **norma**; esta matriz es la **evidencia** de cómo y por qué esa norma llegó a existir. Permite responder «¿por qué existe este principio?» con un rastro auditable —bloque de descubrimiento → decisión → artículo constitucional— en lugar de una interpretación.
>
> - **Fecha:** 2026-07-19
> - **Fuentes:** `_descubrimiento-fase-0A.md` (bloques ratificados) · `01-constitucion-maestra.md` v1.0 · `_auditoria-coherencia-fase-0B.md`

## Tabla 1 — Bloque de descubrimiento → Artículo constitucional

| Bloque | Qué decidió | Artículo(s) |
|---|---|---|
| **1** — ¿Qué es SOEC? | Nueva categoría: Sistema Operativo Empresarial Cognitivo; centro = relación empresa↔mundo; ECE como mecanismo; ciclo Comprender→Aprender→Adaptarse→Orientar | 2.1, 2.6 |
| **2** — ¿Qué problema resuelve? | Enfermedad = incapacidad cognitiva creciente ante una realidad que se acelera; amplificar, no sustituir | 2.7, 2.3, 2.4 |
| **3** — ¿Por qué el mundo lo necesita? | Necesidad permanente + consecuencias sociales + medio recién posible; independencia tecnológica; visión universal / ejecución progresiva; enunciado civilizatorio | 2.7, 2.5, Preámbulo |
| **4** — ¿Qué lo diferencia? | Diferenciación por misión (no por tecnología); infraestructura cognitiva (posicionamiento); integrar→absorber; descubrir preguntas | 2.2, 2.1, 8.1 |
| **5** — ¿Propósito a 20 años? | Propósito raíz = preservar la autonomía intelectual (fin); amplificar = medio; Deber Permanente; salvaguarda «no sustituir la comprensión» | 2.2, 2.3, 2.4, Preámbulo |
| **6** — ¿Qué jamás cambia? | Estructura Deber/Límites/Carácter; Prueba de Propósito; tres niveles de permanencia; Comprensión sobre Datos = identidad; Responsabilidad Proporcional al Impacto = gobernanza | 2.3, 2.4, 2.5, 8.1, 8.2 |

## Tabla 3 — Glosario de términos con significado fijado

| Término | Significado en SOEC | Artículo |
|---|---|---|
| **Propósito** | Fin último: preservar la autonomía intelectual | 2.2 |
| **Misión** | Tarea permanente / medio: preservar, ampliar y transmitir la comprensión (el Deber) | 2.3 |
| **Comprensión viva y unificada** | Requisito identitario permanente; hoy encarnado en el ECE | 2.6 |
| **ECE** | Estado Cognitivo Empresarial: mecanismo actual, no identidad | 2.6 |
| **Infraestructura cognitiva** | Posicionamiento (Nivel II), no afirmación de identidad | 2.1 |
| **Amplificación** | Medio para el propósito; nunca sustitución | 2.2, 2.3 |
