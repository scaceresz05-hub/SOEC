## Principios rectores (borrador)

1. **Fundación antes que funcionalidad.** La Fase 0 construye la ingeniería del proyecto; el producto se desarrolla sobre una única fuente de verdad.
2. **Una sola raíz oficial:** `C:\proyectos\SOEC`. Sin estructuras paralelas.
3. **Documentar la decisión, no solo el resultado.** Todo cambio de rumbo queda en `docs/adr/` o `docs/decisions/`.
4. **Inspeccionar antes de modificar.** Verificar la estructura real; no asumir.
5. **Continuidad multi-año.** Se optimiza para que el proyecto sea comprensible y mantenible durante años, no para velocidad de corto plazo.
